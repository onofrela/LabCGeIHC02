Repositorio que almacena las prácticas y ejercicios de Laboratorio de Computación Gráfica e Interacción Humano Computadora.

Para esta práctica, se considerará el uso del auto anterior para aplicar nuevas luces como la del cofre y la luz trasera, así como la lógica de encendido, apagado y orientación de la dirección de éstas.

También, se aplicará la lógica de encendido y apagado de la farola y de un nuevo modelo que tendrá una iluminación independiente.
